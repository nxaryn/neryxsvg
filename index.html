The idea

Visual editing without losing the code.

NeryxSVG sits between drawing and writing SVG by hand. Create elements on a coordinate-based canvas, move them visually, then use exact numerical controls whenever you need precision.

Built for precision

Everything revolves around real SVG.

NeryxSVG doesn't fake a vector editor with HTML positioning. The canvas works with actual SVG elements and actual SVG coordinates.

⌖
Coordinates

Work on a real coordinate system

Use a Cartesian-style SVG canvas with rulers, grid spacing, snapping, zooming, panning and live cursor coordinates.

◈
Elements

Native SVG primitives

Create rectangles, rounded rectangles, circles, ellipses, lines, polygons, polylines, paths and text.

⌗
Precision

Numbers when you need them

Position and resize objects numerically, edit points directly and control the exact values behind your design.

Developer focused

The code isn't hidden.

NeryxSVG isn't trying to abstract SVG away from you. It makes the SVG easier to create.

Every shape you create is a real SVG element, giving you output that can be used directly in websites, applications, games, interfaces, documentation and other SVG-compatible projects.
