01 / ABOUT

What is NeryxSVG?

SVG editing without hiding the SVG.

NeryxSVG is a free browser-based SVG editor designed around a simple idea:

Draw → Drag → Fine-tune → Export

You can create SVG elements visually, move them around the canvas, adjust their properties numerically, and export the resulting SVG code.

Instead of manually guessing coordinates and repeatedly editing SVG source code, NeryxSVG lets you create the graphic visually first and then fine-tune the exact values when precision matters.

The goal is not to replace SVG code. The goal is to make creating that code easier.

02 / WHY NERYXSVG

Built between visual editing and code

A developer-focused approach to SVG creation.

SVG is powerful, but manually building graphics can become frustrating as the number of elements, coordinates, paths, and dimensions increases.

Traditional visual editors make positioning easy, while writing SVG manually provides direct access to the source. NeryxSVG is designed to sit between those two workflows.

Visual

Create and move elements directly on the SVG canvas instead of manually calculating every coordinate.

Precise

Switch from dragging to numerical controls whenever exact positioning or dimensions are required.

Portable

Export your work as normal SVG code that can be used in other projects.

Developer-focused

NeryxSVG does not require a proprietary format for the final SVG output.

06 / EXAMPLE

From canvas to SVG code

You do not need to calculate every coordinate by hand.

Suppose you want to create a circle positioned at X 250 and Y 150 with a radius of 50. 

<circle cx="250" cy="150" r="50" />

Instead of manually writing those values first, create the circle on the canvas, drag it into position, and then fine-tune its values. 

X:       250


Y:       150
Radius:   50

NeryxSVG handles the connection between the visual element and the SVG source.

07 / FOR DEVELOPERS

Built for developers

The code is part of the workflow, not something hidden away.

NeryxSVG is designed for people who already work with code and want a faster way to create SVG graphics.

The final output is normal SVG. You can take the generated code and place it into a website, web application, game interface, documentation page, icon system, or another SVG-compatible project.

NeryxSVG does not require you to keep your work inside a proprietary project format just to use the result.

08 / RUNNING LOCALLY

Run NeryxSVG locally

Clone the source and run it from your own machine.

NeryxSVG can be downloaded from the public repository and run locally without a special application or build system.

1. Clone the repository 

git clone https://github.com/nxaryn/neryxsvg.git

2. Enter the project directory 

cd neryxsvg

3. Start a local web server 

python -m http.server

Open the local address provided by the server in your browser.

Running the project locally makes it possible to experiment with the source, develop new features, work offline, or create your own hosted version.
